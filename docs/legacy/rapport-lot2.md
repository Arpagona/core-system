Limites : le registre vérifie noms, chemins, dépendances internes, présence des IDs dans les sources et existence de tests ; il ne vérifie ni leur sens ni leur qualité. Guardian ne comprend pas le code, ne prouve pas l'exhaustivité des API, et ne vérifie pas lui-même la CI ; les signaux de chemins sont approximatifs. Le code PR peut modifier ces contrôles, qui ne sont donc pas indépendants de l'auteur. La revue indépendante humaine reste nécessaire.
