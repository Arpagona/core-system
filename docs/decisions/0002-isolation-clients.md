# ADR 0002 — Isolation clients

Date : 2026-11-10. Statut : principe retenu, mécanisme à décider.

Décision : séparation stricte des environnements et données par client. Options à comparer : déploiement chez le client, instances distinctes sur infrastructure ARPAGONA. Préciser réseau, stockage, accès modèles, journaux, secrets, sauvegardes et administration. Une instance distincte ne démontre pas à elle seule la confidentialité. Aucune architecture d'isolation complète validée à ce stade.
